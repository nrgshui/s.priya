# Shubhangi Priya — Knitwear & Menswear Designer Portfolio

> **"NEVER BLEND IN"** — A portfolio for **Shubhangi Priya** (Assistant Manager Kidswear at DMart, Senior Executive Menswear Designer at Style Union, B.Des Knitwear Design from NIFT Mumbai).

Live Demo & Hosting: [https://nrgshui.github.io/s.priya/](https://nrgshui.github.io/s.priya/)

---

## 🌟 Key Highlights

- **TOONHUB 3D Collectible Figurine Carousel**:
  - Full-viewport interactive hero carousel featuring **7 character figurines of Indian origin** (3 Men + 4 Children).
  - High-energy Anton display typography (`SHUBHANGI PRIYA` ghost text), glassmorphic clarity cards, and synchronized 650ms cubic-bezier color crossfades.
  - Seamless toggle between the **Indian Origin Series (7)** and **Figma Classic (4)**.
- **Interactive 3D Tailoring Dress Form Atelier (Three.js & R3F)**:
  - Realistic haute couture tailor's mannequin with dynamic cloth physics.
  - 5 authentic luxury fabrics: *Mulberry Silk Charmeuse, Heavy Liquid Satin, Cashmere-Silk Knit, 290 GSM Cotton Looper, and Crinkled Silk Linen Voile*.
  - Real-time cloth ripples, lighting controls, wireframe mode, and Style Union Pantone swatches.
- **Glassmorphic Cards with Woven Fabric Textures**:
  - Every card features an authentic textile weave background (*Herringbone, Diagonal Twill, Linen Crosshatch, Ribbed Knit, Technical Mesh*).
  - Distinct purpose-driven color coding for trends, blueprints, timeline, and dye lab swatches.
- **Light & Dark Theme System**:
  - One-click theme switcher in the hero header and sticky navigation bar.
- **Style Union & DMart Collection Showcase**:
  - 9 seasonal trend stories (*Retro Re-do, Nautical Island Boy, Serene Futurism, Engineered Nature, Desert Nomad, Preppy Outdoors, Modern Mystic, Tropadelic, Bohemian Alchemist*).
  - Production tech packs with real mill specs (290 GSM cotton looper unisets, flat knits, cuban mood shirts, graphic sweats).
  - Pantone master swatch library with one-click code copy.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Glassmorphism + Custom SVG Woven Fabric Weaves
- **3D Graphics**: Three.js + `@react-three/fiber` + `@react-three/drei`
- **Icons & Micro-interactions**: Lucide React + Canvas Confetti
- **CI/CD & Hosting**: GitHub Actions + GitHub Pages
